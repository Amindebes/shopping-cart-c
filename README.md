# Shopping Cart Program in C

A C program that simulates a basic shopping cart and allows users to add and manage items.

## Overview

This project demonstrates fundamental C programming concepts by implementing a simple shopping cart program.

The program uses functions, arrays, loops, conditional logic, and user input to manage items in a shopping cart.

## Concepts Demonstrated

- C programming
- Arrays
- Functions
- Loops
- Conditional statements
- User input
- String handling
- Basic program logic

## How It Works

The program allows the user to interact with a shopping cart by entering item information and performing different cart operations.

The program processes the user's input and uses functions to organize the shopping cart functionality.

## Compilation

Compile the program using GCC:

gcc main.c -o shopping_cart

## Running the Program

On Linux or macOS:

./shopping_cart

On Windows:

shopping_cart.exe
